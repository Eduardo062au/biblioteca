# biblioteca

Sistema que gerencia livros e empréstimos de uma biblioteca.

Como executar
Instale as dependências:
   npm install

   Execute o projeto:
   npm start

   O que o sistema faz
- Cadastra livros no acervo
- Registra empréstimos de livros
- Consulta se um livro está disponível ou não

Testes realizados
- Cadastro de 3 livros: O Senhor dos Anéis, Harry Potter e Game of Trones
- Empréstimo do livro "O Senhor dos Anéis"
- Consulta de disponibilidade dos livros
- Tentativa de consultar livro inexistente (código 1000)
